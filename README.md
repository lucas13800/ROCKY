# 🐾 Les Aventures de Rocky

Un mini site de jeux pour Rocky, chien d’Aix-en-Provence, avec Lucas, Chiara, Trinity, Florane, Léo et grand-père Diego.

**8 jeux** : Course avec Lucas, Le goûter de Chiara, Mémo de la famille, Une journée à Aix, Quiz Aix et chiens, Rocky Clicker, Chasse aux écureuils, Le coin blagues. Plus un carnet de médailles et un générateur de carte postale.

## Jouer
Ouvre le site : `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`

## Modifier
Tout est dans `index.html` (un seul fichier, photos incluses). Les blagues sont dans la liste `JK`, les questions du quiz dans `QZ`, l’histoire dans `ST`.

## Publier avec GitHub Pages
1. Crée un dépôt (ex. `rocky`).
2. Envoie `index.html`, `README.md` et `.nojekyll`.
3. Settings, puis Pages, puis Branch `main` et dossier `/ (root)`, puis Save.
